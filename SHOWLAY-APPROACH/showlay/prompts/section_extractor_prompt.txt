Question type definitions:
- Text Box: short single-line free text field.
- Text Area: longer multi-line free text field.
- Display: static instruction, legal text, explanatory text, section title, or other visible content with no user input.
- Checkbox: one standalone checked/unchecked item with no peer options.
- Checkbox Group: multiple options where the user may select more than one; use for "check all that apply" style prompts.
- Radio Button: multiple options where the user should select exactly one answer.
- Dropdown: compact single-select menu style field.
- Date: date field, including DOB, begin date, end date, revision date, or mm/dd/yyyy-style input.
- Number: numeric-only field, including score, amount, count, age, quantity, or total.
- Equation: calculated field or subtotal/total derived from other fields.
- Signature: signature line or signature control.
- Group Table: repeatable table/grid parent; emit table columns or child fields as following rows when visible.
